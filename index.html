关于服务器

悠哉世界，一位腐竹以及管理员们共同维护着的服务器，2025 年 6 月开服至今。
开始，只有服主在服里和班上同学游玩，后面发现班上游玩国际版的同学太少，遂决定开放。
自 2026 年 1 月起，悠哉世界正式从 Bedrock 版迁移至 Java 版，以更开放、更灵活的模组生态，迎接更广阔的创造可能。此次迁移使服务器获得了 Java 版独有的红石机制、命令系统与社区资源，让建筑、生电与冒险体验全面提升。
如今，我们依托 Java 版强大的服务器支持，实现了更稳定的多人在线环境、更丰富的游戏内容扩展，并逐步构建起兼容原版与轻度模组的特色玩法体系，致力于为每一位玩家打造更自由、更持久的游戏家园。


——Youzai World Team

服务器规则

禁止行为

包括但不限于

  1. 除矿透外的任何形式的作弊（例如使用修改器、外挂等），矿透行为太离谱（例如矿透一大堆矿物然后到出生点乱撒）也禁止
  2. 在服务器公屏、QQ 群发布任何违法犯罪的内容，多次引战、辱骂、造谣和恶意攻击他人
  3. 过于频繁的（每周发广告次数超过 3 次）在服务器公屏或QQ群发布广告
  4. 虽然服务器允许建造生电机器，但恶意卡服、影响服务器正常运行的行为仍然禁止

违反规则将根据情节严重程度受到警告、封禁等处罚

警告

使用修改器、外挂作弊、在服务器公屏、QQ 群发布任何违法犯罪的内容，多次引战、辱骂、造谣和恶意攻击他人和恶意卡服、影响服务器正常运行在悠哉世界被视为重罪，不可原谅
服务器公屏聊天消息和QQ群聊天消息是可以查询的，如果有充分证据证明你触犯了这 3 条规则，你将会被永久封禁并踢出群聊，且没有任何申诉机会
